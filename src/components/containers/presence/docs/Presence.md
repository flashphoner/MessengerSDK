Use the **Presence** SDK to manage server connections, update your status, and interact with friends.


## Key Features

- **Server Connection**: Connect or disconnect from the server.
- **Change Status**: Set your availability (Online, Idle, Do Not Disturb, Invisible).
- **Friends List**: View and interact with friends.

## How to Use

### 1. Server Connection

- Connect or Disconnect from the server.
- Status updates automatically (e.g., **CONNECTED** or **DISCONNECTED**).
- Verify credentials and server URL if issues arise.

### 2. Change Status

- Select your status from the dropdown:
  - **Online**: Available.
  - **Idle**: Inactive.
  - **Do Not Disturb**: No interruptions.
  - **Invisible**: Appear offline.
- Status updates in real-time for friends.

### 3. Friends Management

- View friends' names, emails, and statuses.
- Friends' statuses update automatically.
